# PS3 Package Studio for Windows

This release brings the standalone PS3 Package Studio from the combined edition into the existing PS1 and PS2 Classics Package Studio repository. Download the Windows ZIP, extract it, and open **PS3 Package Studio.exe**.

## Changes in this release

- New electric-blue PS3 console and package Windows icon.
- PC-only manual previews for PS1 and PS2. Missing, damaged, or downloading manuals do not block builds.
- Built-in PS1 and PS2 workflows exclude console manuals. Supported external-engine packages are checked and rebuilt if recognized manual entries are found.
- Faster final PKG writing for recognized bundled runtimes.
- PS1 and PS2 artwork previews, standard and 3D covers where available, local caches, and optional online lookup.
- Disc, PS1 audio, artwork, and manual indicators with status explanations.
- Offline Redump checks for supported PS1 CUE/BIN layouts and PS2 DVD ISOs.
- PS1 LibCrypt lookup, supported single-disc patching, custom PS1 configurations, and supported multi-disc workflows.
- PS2 compatibility profiles, custom and advanced configurations, and game-specific widescreen matching.
- Sequential queues, illustrative PS3 menu preview, supported menu-audio controls, build activity, progress, cancellation, and completion location.
- Bundled engines and runtimes for standard workflows. No separate Python installation or packaging application is required.

PS1 and PS2 manuals are previewed on the PC. Optional online lookup and community compatibility reports require internet access. A compatible PS3 environment and game-specific configuration may be needed. Console gameplay has not been verified in this release check.

The bundled PS3 placeholder activation file has unconfirmed redistribution rights. The project README includes full feature details, format limitations, and credits.
